# Python 源码逐行学习注释设计

## 目标

为项目中所有包含代码的 Python 文件补充面向 Python/FastAPI 初学者的中文学习注释，不修改任何可执行代码、字符串、接口或运行行为。空的 `routers/__init__.py` 保持不变。

## 注释规则

- 每个有效逻辑行前说明该行的用途和关键语法。
- 连续参数行、连续中间件配置项可共用一段注释，避免重复同一句话。
- 保留已有文档字符串、空行、代码顺序和格式。
- 解释项目中实际出现的概念，不扩展无关知识。

## 验收标准

- Python 文件的 Git diff 只出现新增注释。
- `python -m py_compile` 对全部目标文件通过。
- 与 Git 基线比较，全部目标文件的 Python AST 保持一致。
- 文件仍是 UTF-8，原有中文和 Emoji 不产生乱码。
