# Animal Island 学习路线图主题设计

## 目标

将 `ai-learning-roadmap.html` 从深色仪表盘统一迁移为 `animal-island-ui` 的温暖动物岛风格，同时保持现有学习数据、打卡、本地存储、折叠、导出和响应式行为不变。

## 视觉系统

- 使用奶油纸张背景、木棕正文、湖水青主色和珊瑚橙点缀。
- 标题、正文、标签和表单统一使用圆润中文字体栈。
- 卡片统一采用 18–24px 大圆角、深浅双层边框和底部厚阴影，形成轻量 3D 质感。
- 按钮、输入框、下拉框、弹窗、进度条、复选状态和提示消息共用一组 CSS token。
- 顶部加入动物岛插画和叶片装饰；装饰不遮挡内容、不参与交互。

## 页面结构

- 保留现有顶部操作区、左侧进度/导航、右侧阶段内容的双栏信息架构。
- 将顶部操作区改为动物岛横幅；在小屏幕上隐藏非必要装饰并允许按钮换行。
- 阶段、周、天三级折叠层级保持不变，用统一的卡片层次、颜色和交互反馈表达嵌套关系。
- 弹窗和 toast 与主页面采用同一主题，不保留任何深色仪表盘组件。

## 实现边界

- 不引入 React、构建工具或新的运行时依赖。
- 不改写路线图数据和业务函数；仅在必要处增加主题类名、装饰标记和可访问性属性。
- 上游公开素材仅复制页面实际使用的少量图片到本地资源目录，并保留来源说明。
- 打印模式继续输出清晰的白底内容。

## 验收

- 桌面和移动端均无横向溢出，正文和控件对比度可读。
- 所有可见组件使用同一套颜色、圆角、阴影、字体和交互状态。
- 打卡、折叠、重置、导出、弹窗、笔记和 localStorage 行为保持可用。
- 页面在本地直接打开时不依赖远程字体或远程图片。
