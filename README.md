# 📋 学习路线图

6 个月 · 每天 3 小时 · 140 天详尽指南

## 快速开始

```bash
# 直接用浏览器打开
open ai-learning-roadmap.html  # macOS
start ai-learning-roadmap.html # Windows
```

不需要安装任何依赖，纯静态 HTML 文件。

## 功能

- **📊 进度追踪** — 点击每天的复选框标记完成，自动计算各阶段和总体进度
- **📝 学习笔记** — 笔记实时保存到 IndexedDB，支持多行输入，侧栏笔记列表
- **📅 每日打卡** — Ctrl+K 弹出打卡窗口，记录日期、学时、笔记
- **📖 富文本教程** — 140 天详细指南，支持列表、代码高亮、Java 对照卡
- **💾 数据持久化** — 进度存 localStorage，笔记存 IndexedDB，导出备份 JSON
- **🎨 白色手套光标** — 纯 CSS 内联 SVG

## 目录结构

```
├── ai-learning-roadmap.html   # 主文件（离线可用）

```

## 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+K` | 打开打卡窗口 |
| 点击阶段/周/天标题 | 展开/折叠 |
| 点击 ☐ 复选框 | 标记完成/取消 |

## 浏览器支持

Chrome / Edge / Firefox / Safari 均支持。
